SJGP · district monitoring console · layout study

Ten industry-standard layouts, each built with the console's own data

Every mockup below uses the same token set, the same chart helpers and the same sample figures, so a difference you can see between any two of them is a difference of layout and not of styling. Officer names, village names and all figures are invented: this repository is public and the district's roster is not in it. Each page carries filters, a chart, a table or list, a status element, and the loading, empty and error states of one widget — switch them in the black bar at the top of any mockup.
